# 跨境电商利润模型计算器

一个面向跨境电商运营、定价和成本核算的单品利润计算器。选择销售平台并输入售价、推广、物流、仓储、平台、产品及分摊成本后，页面会统一折算币种，实时计算毛利、毛利率、净利润和净利率。

**在线使用：** [https://kris-2023.github.io/crossborder-profit-calculator/](https://kris-2023.github.io/crossborder-profit-calculator/)

> 平台选择仅用于业务标记和结果展示。本项目不内置、猜测或自动套用任何平台费率；佣金、物流、仓储及其他费用均由用户根据实际合同、账单或后台数据填写。

## 功能

- 支持 Amazon、Walmart、Shopify、Wayfair、Temu、TikTok Shop、eBay 和自定义平台。
- 售价可用 USD 或 CNY 输入，并折算为所选平台 / 报告币种。
- 平台 / 报告币种支持 USD、CNY、EUR、GBP、CAD、JPY、AUD 和 MXN。
- 推广、物流、仓储及平台等直接成本可按固定金额或售价百分比录入；分摊成本按售价百分比录入。
- 产品成本可用 USD 或 CNY 输入。
- 默认汇率为 `1 USD = 6.78 CNY`，可按实际结算汇率修改。
- 实时展示直接成本、毛利、分摊成本、净利润及相应售价占比。
- 支持盈利和亏损结果，不会因总成本超过售价而阻止计算。
- 可将结果复制为图片，便于发送和审核。
- 可将当前利润模型导出为 Excel，保留基础参数、费用明细和利润结果。
- 响应式布局，可在桌面和移动设备使用。

## 计算口径

本工具按单件成交口径计算。百分比费用均以折算后的平台币售价为基数。

```text
直接成本 = 推广费用
         + 物流与仓储费用
         + 平台费用及其他直接成本
         + 产品成本

毛利 = 平台币售价 - 直接成本
毛利率 = 毛利 / 平台币售价 × 100%

净利润 = 毛利 - 分摊成本
净利率 = 净利润 / 平台币售价 × 100%
```

金额模式与比例模式的含义：

- **金额模式**：输入值直接作为当前平台 / 报告币种下的成本金额，页面自动反算其售价占比。
- **比例模式**：输入值作为售价百分比，页面自动计算对应金额。
- **产品成本**：按所选 USD 或 CNY 输入币种折算，不使用百分比模式。
- **空白可选成本**：按 `0` 参与计算。

页面使用完整数值精度进行计算，金额和百分比的格式化仅影响显示，不改变内部计算结果。JPY 默认不显示小数，其他已支持币种通常显示两位小数。

## 币种与汇率

USD 与 CNY 之间以用户填写的美元兑人民币汇率换算：

```text
CNY → USD：人民币金额 / USD-CNY 汇率
USD → CNY：美元金额 × USD-CNY 汇率
```

当平台 / 报告币种为 EUR、GBP、CAD、JPY、AUD 或 MXN 时，需要额外填写：

```text
1 平台币 = ? CNY
```

所有金额先换算为人民币中间值，再折算为平台 / 报告币种。工具不会联网获取实时汇率；请按实际收款、结汇或财务核算口径更新汇率。

## 图片与 Excel 导出

- **复制为图片**：生成当前利润结果的摘要图片，并尝试写入系统剪贴板。浏览器不支持图片剪贴板或未授予权限时，可按页面提示改为下载 PNG。
- **导出 Excel**：下载当前商品信息、币种汇率、费用明细、金额占比、毛利和净利润结果，便于归档或继续分析。

导出的结果是本次输入和当前汇率下的测算快照。后续修改页面参数不会自动更新已经导出的文件。

## 隐私

所有输入、计算以及图片 / Excel 生成都在当前浏览器本地完成。项目没有后端数据库，不会主动上传产品型号、售价、成本或利润数据。

使用 GitHub Pages 等静态托管打开页面时，托管服务仍会处理正常的页面访问请求，但表单中的经营数据不会由本项目提交到服务器。刷新或关闭页面前，请先导出需要保留的结果。

## 本地运行

项目是纯静态 HTML、CSS 和 JavaScript，不需要安装依赖或构建。

直接双击 `index.html` 即可进行基础计算。为了获得更稳定的剪贴板和文件导出体验，建议在项目目录启动本地 HTTP 服务：

```powershell
py -m http.server 4173
```

然后访问：

```text
http://127.0.0.1:4173/
```

如果系统使用 `python` 命令：

```powershell
python -m http.server 4173
```

## GitHub Pages

本项目不需要构建步骤，可直接从仓库根目录发布：

1. 打开 GitHub 仓库的 **Settings → Pages**。
2. 在 **Build and deployment** 中选择 **Deploy from a branch**。
3. 选择默认分支（通常为 `main`）和 `/ (root)` 目录。
4. 保存并等待 GitHub Pages 完成部署。

## 测试

需要 Node.js。进入项目目录后运行：

```powershell
node --test
```

测试重点应覆盖币种换算、金额 / 百分比费用、毛利与净利公式、负利润、输入校验以及导出数据口径。

## 已知边界

- 这是单品、单件成交利润模型，不是订单、店铺或多 SKU 财务报表。
- 平台名称仅作标签，不会自动提供佣金、FBA、支付、服务费或其他平台费率。
- 工具不连接平台 API、ERP、广告账户、仓库系统或实时汇率服务。
- 当前售价和产品成本输入币种限于 USD / CNY；其他已支持币种用于平台 / 报告结果。
- 所有百分比费用都按售价计算，不处理阶梯费率、最低收费、复合税费或费用之间的嵌套计费。
- 税费、退款、折扣、汇损等只有在作为相应成本手动录入后才会进入结果。
- 本工具提供经营测算，不替代会计、税务、法律或平台结算意见。
- 浏览器的剪贴板权限与下载策略可能影响图片复制和文件导出。
- 当前页面不会自动持久化经营数据；刷新或关闭页面前请导出需要保留的结果。
